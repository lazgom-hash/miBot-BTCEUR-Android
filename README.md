# miBot BTC/EUR Downloader para Android

Aplicación Android que descarga velas de BTC/EUR del mercado Bitstamp y las exporta al formato BIN de miBot (20 bytes OHLC por vela).

Compilación automática con GitHub Actions. No requiere claves ni cuentas en exchanges. Datos de Bitstamp, no de OKX.

Para construir una APK: consultar **Actions → Compilar miBot BTC-EUR APK**. El artefacto de la ejecución contiene `app-debug.apk`.
